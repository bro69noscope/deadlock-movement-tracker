#### Current Features

- 📍 Save an in-game position with a name (=instance)
- 🔍 Search for an instance and tp to it (supports approximative search terms like `zip boost green`
  for `zipline dash from yellow edgeboost to green`)
- ✅ Press success/fail key to tp back to the starting position and declare your last run as
  passed/failed
- 🎉 Get a popup message when a route was succeeded `x` times in a row
- ⚡ Practice routes without infinite stamina, immediately fully replenishing it between attempts
- ✏️ Rename & Reposition your current instance
- ↩️ Forget your last run's success/fail if you missclicked (press multiple times to forget multiple
  times)
- 🎲 Randomize your starting positions to avoid practicing the exact same start (prefixing a route
  name with `randoff` or other `prefixes` disables this)
- ⏱️ Auto-start a timer on your first movement input to measure how long running a route takes you
- 🐌 Slow down in game time to practice hard techs more slowly (your slowed/sped up stats are
  tracked, separately than regular speed)
- ⌨️ 95% Customizable hotkeys (supports modifiers like `!q` (alt-q))
- 📊 Show a graph showing your success percentage over time for each instance (requires Python)

## Setup

### Requirements
- Windows
- AutoHotkey v2
  https://www.autohotkey.com/
- Deadlock running in Windowed Fullscreen

---
### Download
- Click Code → Download ZIP on GitHub, or clone the repository
- Extract it wherever you want

---

### Enable console logging
The tracker reads positions from Deadlock’s `console.log`.

In Steam:
1. Right-click Deadlock → Properties
2. Open Launch Options
3. Add: `-condebug`

---

### (optional) Configure Deadlock path and hotkeys
1. Locate `user_settings.ini` in the repository root
2. If you've installed Deadlock in a different location that the steam default, adjust:
```
    [deadlock]
    root=C:\Program Files (x86)\Steam\steamapps\common\Deadlock
 ```
3. (optional) You can copy and backup `user_settings.ini` To be able to restore defaults easily.
   Change the values in this file to customize the settings for this script.
4. (optional) You can create `user_settings.local.ini` and paste `user_settings.ini` contents in it
   (create the local file right next to the original one). This will make every setting that you
   change in `user_settings.local.ini` take priority.

---

### First run 👟
- Double-click `DMT.ahk` in the repository root. (that means the highest level in the downloaded
  directory 📁)

On first run the tracker will automatically:
- Install or update `mvtrack.ps1` in your Deadlock folder
- Install or update `mvtrack_config.cfg` and `mvtrack_pos.cfg` in `game\citadel\cfg` with your
  customized binds
- Prompt you to add a few minimal required lines in `autoexec.cfg`

Accept the prompt unless you already managed these lines manually.

---

## Using the tracker (some default hotkeys)

- F4 — Save current position as a new route start
- F3 — Switch to an existing route start
- F1 — Mark failed attempt and reset to start
- F2 — Mark successful attempt and reset to start
- F5 — Undo last success/fail entry
- F12 — Close the tracker

- Find out about the more advanced hotkeys by reading `user_settings.ini` !

---

## Troubleshooting
If positions are not saved or restored correctly:

- Verify Deadlock launch options include `-condebug`
- Ensure you accepted the `autoexec.cfg` modification
  (or manually added `sv_cheats 1` and `exec mvtrack_config.cfg` in it)
- Check that the `root=` path in `user_settings.ini` is correct
- Keep in mind conflicts could be possible if you run your own scripts in `autoexec.cfg` that also
  bind the same keys as this script in deadlock

## Uninstalling

- Run `uninstall.ahk` in the repository root to automatically delete the auxiliary script/cfg files
  generated by this script.
- After that you can delete the whole repository directory.
- (If you want to keep your instances data for later use, save `src/tracker_data`)
